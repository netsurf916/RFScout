Step 2

Connect and flash

Connect a supported LILYGO T-Embed CC1101 Plus over USB, then start the installer. RFScout validates the supported hardware profile at startup. Chrome or Edge on a desktop operating system is recommended because Web Serial support is required.

This browser does not support Web Serial. Use a current Chromium-based browser. Web flashing requires a secure HTTPS connection.
Clean-install behavior

The combined image is flashed from offset 0 and can replace internal NVS and other internal-flash state. It does not erase or modify the removable SD card.

Candidate builds are short-lived CI artifacts. Published releases remain the durable, recommended builds.
